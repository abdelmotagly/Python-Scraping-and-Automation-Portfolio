## 🚀 Environment Execution & Getting Started

### Web Applications (Front-End)
No environments or installations are required for the front-end apps. Simply double-click on any `.html` file (e.g., `kanban_board.html`) to launch the interactive interface right inside your web browser.

### Python Backend & Automation Scripts
Ensure you have **Python 3** installed. Install the essential pipeline and parsing libraries prior to launching data or scraping scripts:

```bash
pip install pandas openpyxl beautifulsoup4 requests
```

### Running Console Scripts
Launch any terminal interface, game, or data engine from your command line terminal:

```bash
# Execute automation tasks
python excel_merger.py

# Launch CLI Games
python blackjack_game.py

# Run Security tools
python password_generator.py
```
